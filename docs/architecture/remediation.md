# 分批整改清单

当前部分符合。每批独立分支、说明、回归验收并删除实际已消除的豁免；完成状态和证据见对应分支说明。

## D001：运行器与组装

将具体插件注册移到启动组装入口；RecipeRunner 接收注入的注册表。保留现有公开入口、默认配方、目录哈希、权限预检与审计结果。

已实现分离，本地验收见 [D001](../features/d001-runner-composition.md)。运行器不再引用具体插件；原默认调用由兼容包入口注入工厂。解除的 P5 循环一并移出基线，后续职责拆分见 D002。

## D002：P5 职责

拆出纯交接契约与校验，隔离 Agent 执行、存储和外部验证。回归固定父子路由、取消、hash 和账本恢复用例，不改变审查或授权语义。

已实现 ports 与存储/启动组装分离，本地验收见 [D002](../features/d002-p5-boundaries.md)。本批消除 12 条精确引用。SEC 身份常量已归纯契约，后续响应契约拆分见 D004；当前剩余问题以精确基线为准。

## D003：API 安装

由组装入口安装结果、提交和任务生命周期路由；共享类型与有界读取归所属模块公开接口。保留 HTTP 路径、鉴权、幂等、取消及错误语义。

已实现路由组装分离，本地验收见 [D003](../features/d003-api-composition.md)。五条 API 循环边已移出基线，源码依赖图已无循环；共享契约、请求准入和存储保留原入口兼容。其他越界引用继续按下列批次整改。

## D004：SEC 契约

将响应对象与稳定常量归入纯契约层，具体 SEC 客户端实现该契约。回归严格解析、哈希、时间与来源限制。

已实现共享响应契约分离，本地验收见 [D004](../features/d004-sec-contracts.md)。标准化不再引用具体客户端，原类型和常量导入保留别名；本批唯一违规移出基线。获取和校验方法体、固定配方及数据权限保持。

## D005：适配器共享

消除跨适配器私有 helper 与报告常量引用，稳定契约归属明确。回归离线历史评价、日报、Qlib/bt worker 协议及输出。

## D006：旧引擎

逐项迁移采集、日报和审计组装，保持 agent_engine.py 兼容入口，保留 dry-run、写入失败、消息确认、新闻恢复与幂等行为。不能为了目录迁移推翻已验收路径。

整改完成必须同时更新源码、模块 README、分支说明与精确豁免。禁止通过换模块层级、扩大允许引用或放宽扫描范围隐藏违规。
