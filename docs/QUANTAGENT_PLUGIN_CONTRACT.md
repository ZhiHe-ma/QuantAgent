# QuantAgent Plugin Contract v1

每个插件通过 `PluginManifest` 声明：插件 ID、精确版本、能力、输入契约、输出契约、权限、联网要求、重试安全性、运行方式与目录状态。

首批目录只允许 `plugin_catalog/catalog.json` 中的精选插件。目录状态分为 `verified`、`experimental`、`unverified` 和 `disabled`；未知插件不会自动加载，目录版本与运行实现不一致时启动失败。

## 执行边界

- 读取插件必须通过本次运行允许的根目录检查。
- 报告只能写入本次运行的独立目录。
- 离线运行拒绝任何声明需要网络的插件。
- 权限在创建运行目录前预检；缺少权限时不执行任何步骤。
- SQLite 适配器使用 `mode=ro`，不会迁移或修改原数据库。
- 只有插件明确声明 `retry_safe` 时，未来运行器才能考虑自动重试。

进程内插件只适用于轻量、可信且依赖兼容的能力。重型或冲突依赖后续应使用独立环境和进程；进程隔离本身不等于安全沙箱。
