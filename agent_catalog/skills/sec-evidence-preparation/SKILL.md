# SEC evidence preparation

Use when the fixed P5 coordinator prepares a MARA/Riot FY2025 evidence bundle from an approved, frozen P4 run.

1. Resolve the exact approved source ID in the private registry.
2. Verify the frozen P4 packet chain, four raw SEC response hashes, and report hash.
3. Emit only admitted facts, derived P4 records, and provenance hashes for handoff.

The bundle is a two-issuer sample. It contains no raw SEC response bytes, local source paths, network capability, model output, or trading decision. The coordinator alone chooses the reviewer and supplies the authorized handoff envelope.
